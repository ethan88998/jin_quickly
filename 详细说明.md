## 用户管理系统

### 登录
    - [ ] 接收数据
    - [ ] shouldBindJSON解析数据
    - [ ] 在数据库查询用户名 u.model.  DB.First
    - [ ] 用 ID ==0 判断用记是否存在
    - [ ] 对比密码
    - [ ]  Status 状态是否等于0
    - [ ] 生成JWT  Gentoken
    - [ ] 写入cookie SetCookie
    - [ ] 返回JSON



### 用户数据列表+分页
    ① 读取查询参数
    ② 读取分页参数
    ③ 校验分页数据合法性
    ④ 构建DB，变更切片db := DB.Model()
    ⑤ if 条件 → db.Where，用户名/年龄/注册时间
    ⑥ db.Count  变量total，统计，Error处理错误，  if err ..err != nil
    ⑦ 变更空切片分页查询db.Order.Limit.Offset.Find
    ⑧ JSON 返回


### 删除接口
    1. 选取删除ID
    2. 创建变量 user 用来存储返回的数据
    3. 校验ID是否存在
    4. 操作删除
    5. 返回json

## 前端请求 → req struct → user → 数据库 流程图
        ---------------------------------
        POST /api/addUser
        {
        "username": "test001",
        "password": "123456",
        "age": 20,
        "email": "test001@gmail.com"
        }
        |
        v
        Gin 控制器接收请求
        ---------------------------------
        var req struct {
        Username string `json:"username"`
        Password string `json:"password"`
        Age      int    `json:"age"`
        Email    string `json:"email"`
        }
        c.ShouldBindJSON(&req)
        |
        v
        req struct 对象（临时）
        ---------------------------------
        req.Username = "test001"
        req.Password = "123456"
        req.Age      = 20
        req.Email    = "test001@gmail.com"
        |
        v
        映射到数据库模型
        ---------------------------------
        user := u.User{
        Username: req.Username,
        Password: req.Password, // 可加 bcrypt
        Age:      req.Age,
        Email:    req.Email,
        Status:   1, // 默认启用
        }
        |
        v
        数据库操作
        ---------------------------------
        utils.DB.Create(&user)
        |
        v
        数据库写入成功
        ---------------------------------
        返回 JSON 或重定向
        {
        "msg": "注册成功",
        "token": "xxx",
        "user": { ... }
        }

## 新增用户流程
1. 变量req struct 读取参数
2. C.ShouldBindJSON()接收数据并解析数据
3. 变更count，统计用户名的数量，如>0 用户已存在
4. 把临时接收的数据映射到数据库，写入数据库 user := u.User{}
5. 处理创建错误
6. 创建成功返回json
